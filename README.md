# STB Desktop releases

Public Windows downloads and automatic-update packages for STB Desktop.

Download builds from [GitHub Releases](https://github.com/maamouribilel/STBEMU-releases/releases).

- **Windows x64 installer:** `STBDesktop.App-win-Setup.exe`
- **Portable archive:** `STBDesktop.App-win-Portable.zip`

The installer includes the .NET runtime and installs for the current Windows user. Installed copies can check for updates from the app's Settings.

This repository hosts release downloads and update metadata.
